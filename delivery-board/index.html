CASE · DELIVERY BOARD

AI 开发交付看板

Python 标准库 · REST API · SQLite · 原生前端

把“需求拆成任务、任务推到交付”做成一个能用的看板：三列拖拽、REST API、SQLite 参数化查询、输入校验，并附交付复盘。

在线演示（Render） 回到作品集

01功能

看板

  • 待办 / 进行中 / 已完成三列
  • 拖拽调整状态
  • 关键词搜索与优先级筛选
  • 顶部统计跟随数据变化

后端

  • 任务创建、查询、编辑、状态变更、删除 API
  • SQLite 参数化查询
  • 标题长度、状态、优先级约束
  • 错误统一返回 JSON

02在线演示说明

Render 免费实例闲置会休眠，首次打开约 30–60 秒。演示数据库位于临时文件系统，服务重启后恢复为内置演示任务；本地运行时数据保留。

03演示边界

看板里的任务是演示数据，不包含真实项目或客户信息。这是一个单机演示应用，没有做多用户登录与权限隔离。

相关项目：订单洞察台、网页巡检工作台。
