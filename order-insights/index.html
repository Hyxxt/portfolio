CASE · ORDER INSIGHTS

订单洞察台

Python 标准库 · SQLite · 原生前端

把订单 CSV 变成可执行的客户跟进名单：导入校验 → 去重 → 客户分层 → 复购回访提醒 → 导出。分层规则可解释，不是黑盒打分。

在线演示（Render） 回到作品集

01功能

导入与清洗

  • 订单 CSV 字段校验
  • 按订单号去重
  • 金额、数量、状态合法性检查
  • 内置演示订单数据，可直接试

分层与跟进

  • 按最近购买、频次、金额、品类周期分层
  • 生成复购回访提醒
  • 跟进名单导出
  • 客户状态可标记为待跟进 / 已联系

02在线演示说明

Render 免费实例闲置会休眠，首次打开约 30–60 秒。演示数据库位于临时文件系统，服务重启后恢复为内置演示订单；本地运行时数据保留。

03演示边界

订单与客户全部为程序生成的模拟数据，不含真实个人信息。工具用于演示分层与跟进流程，不构成真实营销建议。
