CASE · WEB CRAWLER

公开网页采集器

Python 标准库 · SQLite · 单文件 exe

只用 Python 标准库实现的公开网页采集器：同源按深度发现、遵守 robots、按站点要求限速、正文提取入 SQLite、导出 CSV/JSON。已打包成 7.5MB 单文件 exe，同事双击就能跑，不用装 Python。

在线演示（Render） 回到作品集

01能力与约束

采集能力

  • 同源按深度发现链接，默认最大深度 3、最多 100 页
  • 遵守目标站点 robots.txt
  • 按站点要求限速，请求间隔 1.5 秒
  • 正文提取后写入 SQLite，可导出 CSV / JSON

实测

  • 单任务 100 页 / 2 分 53 秒
  • 7.5MB 单文件 exe，双击运行
  • 内网地址与非法协议会被拒绝
  • 任务与页面记录持久化，可回看

02在线演示说明

Render 免费实例闲置会休眠，首次打开约 30–60 秒。演示实例仅用于试用采集流程，默认限速；请只采集公开页面，不要用于批量抓取或绕过站点限制。演示数据在服务重启后会重置。

桌面版（exe）保留了完整的本地数据目录，适合实际使用；在线版用于快速了解界面和流程。

03演示边界

采集结果仅用于演示，不包含真实客户数据。工具不登录、不处理验证码、不采集非公开内容。
