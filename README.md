# 黄佑雄 · AI 全栈开发作品集

2027 届全日制大专在读，方向 AI 全栈开发 / AI 应用 / 数据分析，在广州白云，每周可到岗 5 天。

作品集包含 5 个已上线的 Next.js 全栈项目（AI 报价、RAG 知识库、AI 求职匹配、订单跟进、理赔通），以及 pandas 广告数据分析、Python 自动化、影刀 RPA、Coze 工作流等原型。关键金额、判定、匹配分写在确定性代码里，模型只负责理解语言，结果可复核、能演示、有测试。

## 本地预览

```bash
npm run build
npx serve dist
```

或直接用浏览器打开 `index.html`。

## 部署

`npm run build` 会把 `index.html`、`img/`、`resume.pdf` 等复制到 `dist/`，静态托管平台发布 `dist/` 即可。
