CASE · SITE MONITOR

网页巡检工作台

Python 标准库 · SQLite · 后台队列

把“定期看几个网页有没有变化”做成一条可回看的流程：采集 → 文本清洗 → 内容哈希去重 → 历史快照比对 → Markdown 报告。单 worker 队列，支持手动运行和 1–168 小时周期调度。

在线演示（Render） 回到作品集

01流程

每次巡检

  • 按任务配置采集目标页面
  • 清洗正文、去掉导航与模板噪声
  • 内容哈希去重，识别真正变化
  • 与上一次快照比对，生成 Markdown 报告
  • 运行记录可导出 CSV / JSON

调度与边界

  • 单 worker 队列，避免并发压垮目标站
  • 周期调度 1–168 小时
  • 访问限制、超时、异常都有边界处理
  • 报告保存在本地 data / reports 目录

02在线演示说明

Render 免费实例闲置会休眠，首次打开约 30–60 秒。演示实例的 SQLite 和报告目录位于临时文件系统，服务重启后重置；本地运行时数据会保留。

演示只采集公开页面，请勿用于高频轮询或绕过站点限制。

03演示边界

巡检目标使用公开示例页面，不包含真实客户或内部系统。工具不登录、不处理验证码。

相关项目：公开网页采集器、订单洞察台。
