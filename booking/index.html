CASE · BOOKING MVP

美容预约助手 MVP

Python 标准库 · SQLite · 原生前端

门店咨询与预约的最小闭环：顾客问项目与价格 → 提交预约意向 → 门店侧查看与确认。规则写死在代码里，AI 只负责把顾客的话对到服务项目。

在线演示（Render） 回到作品集

01功能

顾客侧

  • 服务项目与参考价展示
  • 按关键词匹配护理项目
  • 预约意向提交：称呼、手机号、项目、日期、时段
  • 过敏、疼痛等敏感描述直接转人工

门店侧

  • 预约列表按日期与时段时间排序
  • 待确认 / 已确认状态流转
  • 手机号格式与必填校验
  • SQLite 持久化

02在线演示说明

Render 免费实例闲置会休眠，首次打开约 30–60 秒。演示数据库位于临时目录，服务重启后预约记录会重置。请勿填写真实手机号。

03演示边界

这是 MVP 演示：没有接入真实门店排班、支付或短信通知，AI 回复只覆盖项目、价格、时段等固定问题。涉及健康与诊断的描述一律转人工。
